Do a workout

The Train journey in Spatial Depth: /train, the live session, the rest timer, the summary, and every sheet between them. Four decisions are open, each with three or four coded options, measured and with a recommendation. Every phone is built at a real iPhone's 390 × 844 pt with iOS sizes (body 17, 56 pt tab capsule) and shown at 77%; it is live, and the chips above it switch its state. Data shapes follow WorkoutPlan, WorkoutSession and SetData in the frontend, with carry-forward previous values from the backend.

The journey

Three jobs, in order of frequency: start today's session, log every set with one hand, finish and see whether it went up. Everything else (calendar, freestyle, swap) is a side path.

StartFrom the Train tab, know what today holds and start it. Today: 2 taps.
Log15-25 sets, each one either right as prefilled (1 tap) or 2.5 kg off. Today: 1 tap, or 5-7 with the keyboard.
FinishFinish, see progress, leave. Today: 2 taps; progress not shown.

The recommended journey, end to end

Next up: Preview stack (A2) · Set logging: Thumb deck (B4) · Rest: Rest dock (C2) · Summary: Session receipt (D2).

  • Tap Start workout: the session slides in and Train steps back in depth (scale 0.94, dimmed, slight blur). Drag from the left edge to go back; the leave sheet asks first.
  • Change kg or reps on the deck (hold to repeat), tap Log set; the rest dock appears above the deck and counts down.
  • One exercise per screen. After its last set the exercise steps back in depth and the next comes forward (1.1 s, as today); the arrows either side of "Exercise 1 of 5" go back or on, and "All exercises" steps the screen back into an overview of the whole workout where any exercise is one tap away.
  • Options (top right): Add exercise, Swap, Finish, Remove, Discard, Ask Geo. Swap opens a search sheet already filtered to the same muscle.
  • Finish (the one orange in the session) fades the receipt in; Done returns to Train, where today's bar grows in and Next up moves to tomorrow.
  • Scroll Train: the tab bar closes into a circle with the Train icon; the header and background layers drift at different speeds.

Decisions respected: glass only on the controls layer (C1/Q3: tab bar, round buttons, sheets, deck, keypad); cards stay solid white. Orb in ink, never orange (Q4). One orange per screen. Muscle map in orange on exercise cards and in ink where an orange button shares the card (C7, Q18). No bounce: every spring settles without overshoot.

Decision (a): live set logging, one hand, mid-workout

Baseline for every option (owner requirement): one exercise per screen. You fill its sets and rest between them; when the last set is logged the exercise steps back in depth and the next one comes forward (Previous reverses it). Progress (Exercise 1 of 5) is always on screen, and an All exercises overview lists every exercise with done, now and next and set counts; tapping one jumps there. The options differ in how sets are logged and how the overview is shown. Each phone starts mid-workout on Barbell Bench Press, set 3.

Every other surface (one recommended design each)

Calendar sheet, freestyle log, swap and add search, How to, the options sheet and the leave sheet. All are also reachable from inside every phone above.

  • Calendar sheet: a month grid replaces the second week strip. Ink dot = done, ring = planned, orange numeral = today. Tapping a day lists its sessions under the grid; a row opens the read-only session. 3 taps to last week's session instead of 4.
  • Freestyle log: same fields as today (name, exercise, sets, reps, rest) with steppers instead of number fields, the exercise picked from the shared search sheet, and Start session as the one orange. Limits match today's NumberField (sets 1-20, reps 1-200, rest 0-600 s).
  • Swap / Add: one sheet for both. Swap opens with the current exercise's muscle pre-selected and keeps the remaining set count and rest; logged sets stay with history. No backend change: it is the existing remove + add, done in one step on the client.
  • How to: numbered steps from the exercise's instructions open inline under the plan line; the C7 muscle map sits in the image slot so licensed form images can replace it later without moving anything.
  • Options and Leave: today's items and confirms, unchanged in behaviour; destructive actions confirm in place, never in a second dialog.

Validation outside this page

Short first-click and 5-second tests, one per open decision, then a 5-user usability script for the whole journey.

(c) Next up, 5-second test

Show /train for 5 s, hide it. Ask: "What is today's workout, and how heavy was your bench press last time?"

Success: names the workout and gives a bench weight within 2.5 kg. Compare A1, A2, A3 across 5 people each.

(a) Set logging, first click

Mid-workout screen, phone in one hand, a water bottle in the other. Task: "You just did 8 reps at 75 kg. Log it."

Success: first touch lands on the control that changes kg (or Log set when the value is already right); set logged within 6 s; no regrip.

(b) Rest timer, first click

Rest running. Task: "Give yourself 15 more seconds."

Success: first touch on +15 within 3 s. Then: "Change your next set to 77.5 kg while you rest": success without closing the timer.

(d) Summary, 5-second test

Show the summary for 5 s. Ask: "Did any lift go up today? Which?"

Success: names Barbell Bench Press. Expected to pass only for D2.
